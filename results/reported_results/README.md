# Results reported in the article

These CSV files contain the clean-data, robustness, sensitivity, and runtime
results reported in the article.

Energy Efficiency and Concrete Compressive Strength use all 768 and 1,030
observations, respectively. The clean-data statistics correspond to these full
datasets.

- `final_clean_result_matrix.csv`: complete 8-dataset × 9-method clean matrix.
- `clean_dataset_ranks.csv`, `clean_friedman_tests.csv`, `clean_nemenyi.csv`, `clean_wilcoxon_holm.csv`: clean-data statistics.
- `robustness_dataset_summary.csv`, `robustness_friedman_tests.csv`, `robustness_wilcoxon_holm.csv`: robustness statistics across datasets.
- `Table_A_...` through `Table_G_...`: tables used in the article.

Runtime varies by hardware. Metric values are reported at manuscript precision.
