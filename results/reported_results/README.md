# Results

These CSV files contain the clean-data, robustness, sensitivity, and runtime
results for the eight regression tasks.

Energy Efficiency and Concrete Compressive Strength use all 768 and 1,030
observations, respectively.

- `final_clean_result_matrix.csv`: task-level MSM and RMSE values.
- `clean_dataset_ranks.csv`, `clean_friedman_tests.csv`, `clean_nemenyi.csv`,
  and `clean_wilcoxon_holm.csv`: clean-data statistical summaries.
- `robustness_dataset_summary.csv`, `robustness_friedman_tests.csv`, and
  `robustness_wilcoxon_holm.csv`: robustness statistics across datasets.
- `Table_A_...` through `Table_G_...`: tables used in the article.

Runtime values depend on the computing environment.
