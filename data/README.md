Datasets are not included in this repository. Prepare the following layout:

```text
data/
├── native/
│   ├── example1.xlsx
│   ├── example2.xlsx
│   ├── example3.xlsx
│   ├── example4.xlsx
│   └── example5.xlsx
└── public/
    ├── ENB2012_data.xlsx

```

Diabetes is loaded directly from scikit-learn. See
[data_sources.md](data_sources.md)
for sources, target selection, and preparation details.
